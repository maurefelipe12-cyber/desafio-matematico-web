Contexto del proyecto

En la vida diaria y en la informática, los patrones matemáticos ayudan a analizar problemas, organizar información y tomar mejores decisiones. En esta página se aplican dos ideas: la serie de Fibonacci para estimar la carga de tareas académicas y los números primos para verificar códigos numéricos con mayor seguridad.

01

Organizador de tareas con Fibonacci

Este simulador ayuda a estimar la carga de una tarea académica. El usuario ingresa las horas estimadas y un nivel de complejidad. Luego, JavaScript genera la serie de Fibonacci y usa el valor correspondiente como puntaje de dificultad.

¿Cómo se aplica Fibonacci?

La dificultad no crece de forma lineal. Una tarea compleja puede requerir mucho más esfuerzo que una simple. Por eso se usa Fibonacci:

0, 1, 1, 2, 3, 5, 8, 13, 21...

La carga final se calcula así:

Carga = horas estimadas × Fibonacci(complejidad)

02

Verificador de código seguro con números primos

Este simulador verifica si un código numérico puede considerarse más seguro usando números primos. Los números primos son importantes en informática porque se usan en conceptos de seguridad, cifrado y protección de información.

¿Cómo se aplica un número primo?

Un número primo es aquel que solo puede dividirse exactamente entre 1 y entre sí mismo. El programa prueba sus divisores y determina si el código ingresado cumple esa condición.

Ejemplo: 67 es primo porque solo se divide entre 1 y 67.

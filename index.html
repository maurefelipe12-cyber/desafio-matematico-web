Simuladores interactivos usando Fibonacci y números primos aplicados a situaciones reales.

Desarrollado por: Felipe Maure

Contexto del proyecto

La matemática y la programación permiten analizar problemas reales de manera lógica. En esta página se aplican la serie de Fibonacci y los números primos para resolver situaciones relacionadas con organización académica, seguridad informática y análisis de patrones especiales.

01

Organizador de tareas con Fibonacci

Este simulador aplica la serie de Fibonacci para organizar tareas académicas según su dificultad. En la vida real, una tarea difícil no solo toma más tiempo, también puede requerir más concentración, organización y esfuerzo.

Por eso se utiliza Fibonacci como escala de crecimiento de dificultad. El usuario ingresa las horas estimadas y un nivel de complejidad del 1 al 8. Luego, JavaScript genera el valor Fibonacci correspondiente y calcula la carga académica total.

¿Cómo se aplica Fibonacci?

La serie utilizada es:

0, 1, 1, 2, 3, 5, 8, 13, 21...

Si una tarea tiene complejidad 6, el programa calcula Fibonacci(6), que equivale a 8.

Carga = horas estimadas × Fibonacci(complejidad)

Con ese resultado, el sistema clasifica la prioridad de la tarea como baja, media, alta o crítica.

Aquí aparecerá el resultado de la tarea.
02

Cifrador de mensajes con números primos

Este simulador protege un mensaje usando un código numérico primo como clave. Los números primos son importantes en informática porque se relacionan con seguridad digital, cifrado y protección de información.

¿Cómo se aplican los números primos?

Primero, el sistema verifica si el código ingresado es primo. Si lo es, se usa como clave para cifrar el mensaje mediante desplazamiento de letras.

Mensaje + clave prima = mensaje cifrado

Si el código no es primo, el sistema no cifra el mensaje porque la clave no cumple la condición de seguridad básica.

03

Detector de Fibonacci primos

Este simulador combina Fibonacci y números primos para detectar patrones numéricos especiales. Primero se genera una secuencia Fibonacci y luego el programa analiza cuáles de esos valores también son números primos.

Los números que cumplen ambas condiciones son poco comunes y pueden utilizarse para análisis matemático, patrones computacionales e identificadores especiales.

¿Cómo funciona el algoritmo combinado?

El programa primero genera la secuencia Fibonacci:

0, 1, 1, 2, 3, 5, 8, 13, 21...

Después analiza cada número para verificar si también cumple la condición de número primo.

Fibonacci + Primo = número especial

Finalmente, el sistema muestra los valores Fibonacci que también son primos.

Conclusión

Fibonacci y los números primos permiten resolver y analizar problemas reales. La matemática ayuda a organizar información, representar crecimiento, identificar patrones especiales y mejorar el análisis lógico dentro de la informática.
